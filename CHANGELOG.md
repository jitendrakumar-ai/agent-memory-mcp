# Changelog

All notable changes to the `agent-memory-mcp` project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-10-25

### Added
- Claude-Mem standard alignment with 3-Layer Memory Architecture (Episodic Memory, Knowledge Graph, Work Pattern Index).
- Multi-IDE configuration support (Claude Code, Cursor, Codex, Antigravity, OpenCode, Windsurf).
- Local SQLite zero-telemetry database storage.
- Automated self-test suite and GitHub Actions CI workflow integration.
- Standardized `SECURITY.md`, `CLAUDE.md`, `Dockerfile`, and `.gitignore`.
