# Security Policy

## Supported Versions

| Version | Supported |
| ------- | ------------------ |
| 1.2.x | :white_check_mark: |
| < 1.2.0 | :x: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in `agent-memory-mcp`, please report it to the **NexusVibe AI Tech Security Team**.

### Security & Privacy Disclosures
- **Local-Only SQLite Storage**: `agent-memory-mcp` operates completely locally using an embedded SQLite database.
- **Zero Telemetry**: No user data, conversation memory, embeddings, or code metadata are transmitted to external servers.
- **Local Execution**: All memory graph queries and operations run entirely within your local environment.

Please do not report security vulnerabilities through public GitHub issues. Email our security team directly or submit a private security advisory on GitHub.
